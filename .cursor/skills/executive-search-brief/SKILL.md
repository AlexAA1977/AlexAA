# Executive Search Brief

**One page.** Sent before or with full CV. Search consultants read this in 60 seconds.

## When to use

- User says: «бриф для хантера», «one-pager», «профиль для search firm»
- Introduction via mutual contact
- Confidential market sounding (not public job post)

## Structure (strict order)

```
[NAME] — [Target positioning line]
Moscow | [email] | [phone] | LinkedIn

POSITIONING (3 lines)
Who you are + scale + domain in one breath.

PROOF POINTS (5 bullets max, numbers mandatory)
• AUM / P&L / team / network / award

CURRENT ROLE (2 lines)
Title, company, since [date], board status.

CAREER ARC (3 lines)
Single-employer progression OR key moves — emphasize build scale.

TARGET (2 lines)
Role, industry, geography — from master-profile North Star.

MOTIVATION (1 line, optional)
Why move now — only if user approves sharing.

COMPENSATION (1 line, optional)
«Ожидания обсуждаемы» or range — user must confirm.

AVAILABILITY
Notice period / start window.
```

## Example positioning line

«Директор по дистрибуции с P&L-ответственностью за AuM 1,15 трлн ₽ и команду 250+ в крупнейшей частной УК России»

## Rules

- No photo, no hobbies (unless user insists — 1 line max)
- No full job history — pointer: «полное CV по запросу»
- Confidential: omit employer name if user requests «blind profile»
- Save as `resume/brief/Aleksey-Alekseev-brief-RU.md` (+ EN variant)
- PDF: add HTML template or export via `resume/generate-pdf.sh` when brief HTML exists

## Handoff

Pull facts from `master-profile.md` + `executive-cv-hr-guru` anchor. Review via `hm-red-team-review` (recruiter lens only).
