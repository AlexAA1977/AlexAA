`Директор по дистрибуции | AUM 1,15 трлн ₽ | HNWI & Premium | УК Альфа-Капитал | Правление`

**About** structure:
1. Hook (1 line): scale + domain
2. Proof (3 bullets): AUM, P&L, team, network
3. Expertise (channels, segments, products)
4. CTA: open to [specific opportunities] — only if user confirms

**Experience:** mirror CV role progression; **do not** paste full CV — 3–5 bullets per current role, older roles compressed.
